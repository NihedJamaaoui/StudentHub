# StudentHub

Application mobile Android de gestion de la vie universitaire : matières,
tâches, échéances, profil étudiant.

## Technologies utilisées
- Android (Java / Kotlin)
- Android Studio (Gradle)
- Git & GitHub
- (à venir) SQLite / Room

## Étapes pour ouvrir et exécuter le projet
1. Cloner le dépôt :
   `git clone https://github.com/<username>/StudentHub.git`
2. Ouvrir le dossier dans **Android Studio** (File → Open).
3. Laisser Gradle synchroniser.
4. Lancer sur un émulateur (API 24+) avec **Run ▶**.
5. Se connecter avec un compte fictif, ou passer par « Créer un compte ».
